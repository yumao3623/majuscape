# Majuscape

Majuscape is a free browser-based capitalization game world for elementary students in Grades 2-5. Its learning target is specific: decide when a word should or should not be capitalized.

## Live production

- Website: [https://majuscape.fun](https://majuscape.fun)
- Hosting: Vercel
- Production branch: `main`
- Deployment: pushes to `main` automatically create a Vercel production deployment
- Status: live with HTTPS, canonical URLs, robots, sitemap, and structured data

## Game routes

- `/` - Majuscape City lobby and capitalization games landing page
- `/games/capitalization-repair` - tap words to fix complete sentences
- `/games/capitalization-sort` - sort contextual word cargo into capitalization gates
- `/games/capitalization-rush` - repair mixed-rule sentences against a timer
- `/capitalization-games` - retained legacy route; permanently redirects to `/`

## Run locally

Use Node.js 20 or newer:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

npx tsc --noEmit

## Content and progression

New game challenges live in `data/gameContent.ts`. The typed content model is in `types/majuscape.ts`. Sentence questions include grade, difficulty, skills, corrected text, token indexes, and rule-based explanations.

Versioned player progress is stored locally under `majuscape-progress-v1`. It includes XP, stars, daily practice streak, best scores, completed rounds, and practiced rules. No account or database is required.

The original 90-question bank, legacy `GameShell`, and its pure game/storage utilities remain in the repository for compatibility and content reference. They are deprecated for the primary UI but intentionally not deleted.

## Production SEO

The production origin is `https://majuscape.fun`. Set `NEXT_PUBLIC_SITE_URL=https://majuscape.fun` in production; code also falls back to that origin. Metadata, canonical URLs, sitemap, robots, Open Graph, manifest, and JSON-LD are generated by the App Router.

The legacy `/capitalization-games` URL permanently redirects to `/`. Only canonical, indexable URLs are included in the sitemap.
